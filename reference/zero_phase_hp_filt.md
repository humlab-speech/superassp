# Zero-phase high-pass Butterworth filter

Zero-phase high-pass Butterworth filter

## Usage

``` r
zero_phase_hp_filt(x, fs, f_p, f_s)
```

## Arguments

- x:

  Input signal

- fs:

  Sampling frequency (Hz)

- f_p:

  Pass-band frequency (Hz)

- f_s:

  Stop-band frequency (Hz)

## Value

Filtered signal
