## Usage

``` r
makeOutputDirectory(outputDirectory, logToFile = FALSE, funName)

makeOutputDirectory(outputDirectory, logToFile = FALSE, funName)
```

## Arguments

- outputDirectory:

  Character path to output directory

- logToFile:

  Logical, whether to create log file

- funName:

  Character, name of calling function
