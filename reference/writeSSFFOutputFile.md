## Arguments

- ssffobj:

  SSFF data object to write

- filename:

  Character string of original filename

- ext:

  Character string of output extension

- outputDirectory:

  Character string of output directory (optional)

- verbose:

  Logical whether to show progress messages

## Value

Logical indicating success
