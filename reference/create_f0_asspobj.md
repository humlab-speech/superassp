Convert SPTK C++ pitch result to AsspDataObj

Convert SPTK C++ pitch result to AsspDataObj

``` r
create_f0_asspobj(pitch_result, windowShift)

create_f0_asspobj(pitch_result, windowShift)
```

## Arguments

- pitch_result:

  List returned from rapt_cpp, swipe_cpp, reaper_cpp, or dio_cpp

- windowShift:

  Frame shift in milliseconds
