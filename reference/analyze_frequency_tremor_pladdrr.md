# Analyze frequency tremor using pladdrr

Analyze frequency tremor using pladdrr

## Usage

``` r
analyze_frequency_tremor_pladdrr(
  sound,
  slength,
  analysisTimeStep,
  minPitch,
  maxPitch,
  silenceThreshold,
  voicingThreshold,
  octaveCost,
  octaveJumpCost,
  voicedUnvoicedCost,
  minTremorFreq,
  maxTremorFreq,
  tremorMagThresh,
  tremorCyclicalThresh,
  freqTremorOctaveCost,
  nanAsZero
)
```
