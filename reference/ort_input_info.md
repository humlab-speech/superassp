# Get ORT session input/output metadata

Get ORT session input/output metadata

## Usage

``` r
ort_input_info(session)

ort_output_info(session)
```

## Arguments

- session:

  An ORT session from
  [`ort_session()`](https://humlab-speech.github.io/superassp/reference/ort_session.md).

## Value

Named list of tensor info (name, shape, type).
