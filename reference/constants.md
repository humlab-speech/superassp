# Package-level Constants for Signal Processing

This file defines package-level constants used throughout superassp for
signal processing, audio handling, and file format specifications.

## Usage

``` r
PHONET_SAMPLE_RATE

DEFAULT_CHANNELS

SACC_SAMPLE_RATE

BROUHAHA_SAMPLE_RATE

MS_TO_SECONDS

US_TO_SECONDS

JSTF_FORMAT_VERSION

JSTF_DEFAULT_COMPRESSION

STANDARD_SAMPLE_RATES

AVQI_MIN_SV_DURATION_MS

AVQI_MIN_CS_DURATION_MS
```
